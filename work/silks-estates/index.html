Silks Estates · Web design & front-end

Moving a property website from generic styling to a reusable design system.

Kydos led the Phase 1 visual redesign for Silks Estates, building a consistent component and token system rather than solving every page with one-off styling.

The challenge

Create a stronger identity without making the site harder to use.

The redesign needed clearer brand expression, navigation and responsive behaviour while preserving the practical property journey.

Kydos role

Design system, front-end components and responsive iteration.

Kydos developed the visual tokens, header, hero, layout utilities, mobile navigation and reusable interaction patterns.

Design system

Consistency before decoration.

The work established the foundation that lets multiple pages feel like one product.

Brand tokens

Palette, spacing, radius, shadow and reusable utility rules built around the Silks identity.

Navigation

A sticky blurred header, active-link treatment and responsive off-canvas mobile navigation.

Hero system

A stronger headline hierarchy, dual calls to action and a clearer opening composition.

Iteration

Feedback changed the build.

The redesign was not treated as a one-shot visual exercise. Iteration restored dropped navigation links, removed an unwanted hero overlay and re-centred content after review.

Responsive behaviour

Desktop and mobile navigation were designed as related parts of the same system rather than separate afterthoughts.

Reusable front-end

The documented stack spans Next.js, React, Tailwind CSS and TypeScript, with component-based implementation rather than static mock-ups only.

What this project shows

A professional website feels designed when the same rules keep working across pages, states and screen sizes.

Need a website that feels like one brand, not a set of assembled sections?
