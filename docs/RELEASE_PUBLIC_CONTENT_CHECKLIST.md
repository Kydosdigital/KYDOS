# Public website release checklist

Status: internal working standard, excluded from Vercel deployments via `.vercelignore`.

Before merging public website changes:

- No internal notes, draft labels, publishing instructions, approval commentary or placeholder staff copy are present in deployable HTML.
- Service and money pages retain useful proof, package detail, process, FAQs and conversion routes when corporate styling changes.
- Real client work is used only where attribution is clear and the underlying asset is suitable for public display.
- Claims and metrics are supported by project records before publication.
- Contact details, company information and office details match the current approved public information.
- Desktop and mobile navigation are checked, including Services dropdown behaviour.
- Forms, telephone links, WhatsApp links and primary calls to action have valid destinations.
- SEO titles, descriptions, canonicals and existing high-value landing-page copy are not removed merely for visual consistency.
- Internal working files remain excluded from deployment.
